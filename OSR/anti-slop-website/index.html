antislop — the filter itself

38 mandatory rules in three tiers: Hard Gate (absolute), Purpose-Gate (technique allowed, reason required), Quality Locks (consistency). Plus Liveliness Toolkit with three dials (ENERGY / RHYTHM / MOTION) and a Design Read, so the result is alive and specific, not just clean.

Copy & Text

antislop-copywriting

Headlines, CTAs, value props, tone. Makes AI text stop reading like AI, without inventing facts.

  • Flags empty vocabulary (unlock, seamless, revolutionary), rule of three overuse, staccato drama
  • Bans em dashes outside carve-out, bold overuse, fabricated specifics
  • Never invents names, numbers, or citations — specificity comes from you

People

antislop-human

Usable by people with different eyes, hands, and setups. Contrast, keyboard, focus, states.

  • WCAG AA contrast checker included (4.5:1 normal, 3:1 large) — script + formula
  • Removes focus outline without replacement is forbidden (R-32)
  • Empty, loading, and error states required (R-27)

Mobile / Responsive

antislop-layoutmobile

Reflow phone to desktop: breakpoints, scale, grids, overflow, tap targets.

  • Two-state layout trap, 100vh bugs, fixed pixel type, columns that do not collapse
  • Tap targets minimum 44px, hover-only interactions flagged
  • Mobile nav patterns: bare hamburger, sticky nav that steals screen

1. Add the filter to your repo

        
Recommended: picker. It asks which skills, where to install, and which agents you use, then copies folders and writes the pointer.

        
npx antislop-ai
# choose ALL, pick your agents, choose this project

        
Or via skills.sh:

        
npx skills add miqdadbadjuber/anti-slop --all
# then run npx antislop-ai once to write the AGENTS.md pointer

        
Or manual (chat window):

        
curl -o antislop.md https://raw.githubusercontent.com/miqdadbadjuber/anti-slop/main/antislop.md
# give the file to your AI + say: follow its install instructions


        
2. Route your agent

        
Your entry file (AGENTS.md / CLAUDE.md / GEMINI.md) should point to the core + the skill for the task.

        
<!-- antislop:start -->
## antislop
For UI, copy, people, mobile layout, or code comments work, read `antislop.md` (core) and then the skill for the task:
- UI / visual: `skills/antislop-ui/SKILL.md`
- Copy & text: `skills/antislop-copywriting/SKILL.md`
- People: `skills/antislop-human/SKILL.md`
- Mobile / responsive: `skills/antislop-layoutmobile/SKILL.md`
- Code comments: `skills/antislop-code/SKILL.md`
Before starting, ask the user when antislop applies: during the work, or after it is done.
<!-- antislop:end -->


        
3. Add your DESIGN.md

        
The filter does not invent beauty. Create DESIGN.md with identity, palette, typography, mood, and dials. Without it, output is labeled draft without direction (R-37).

        See this site's DESIGN.md
