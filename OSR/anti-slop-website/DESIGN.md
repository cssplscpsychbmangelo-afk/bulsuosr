# DESIGN.md — Anti-Slop Command Center

## Identity
A field manual, not a landing page. Think: inspection toolkit for filtering AI slop. Editorial, precise, human. Like a workshop manual you'd mark up with a red pen.

## Audience
Developers and designers who use AI coding agents and are tired of generic AI pages.

## Personality
Direct, technical, craft-driven. Not playful, not corporate. The voice of a senior reviewer who marks your work and shows you why.

## Palette
- Paper: #FFFBF2 (warm off-white, base)
- Ink: #0F0F0C (near-black, primary text)
- Stone: #8A817C (muted neutral, secondary)
- Accent: #E8452A (vermillion — used ONLY for rule numbers, gates, focal actions. One deliberate accent.)
- Neutral base does not count toward palette cap per R-29.
- Reason: Paper/Ink contrast guarantees AA, Vermillion has functional meaning (warning / gate), restrained palette avoids R-29 violation.

## Typography
- Display: Instrument Serif (serif, editorial authority — chosen for manual-like credibility, not the AI default Inter)
- Body: IBM Plex Sans (humanist, highly legible, distinguishes from the geometric sans default)
- Code/Rect: JetBrains Mono (chosen for code/rules — reason is functional: code must be monospaced; not used as aesthetic, so R-06 purposeful)
- Reason: Serif display signals craft/editorial; mono is restricted to code/rules blocks only; sans body ensures readability.

## Dial
ENERGY 2 / RHYTHM 3 / MOTION 1
- Energy 2: precise but not flat, strong headings, deliberate accent.
- Rhythm 3: highly varied section heights and layouts — hero narrow, rules grid dense, labs full-bleed, gate compressed. No uniform spacing (fixes R-05).
- Motion 1: almost static; only functional transitions (focus, toggle). No decorative animation (fixes R-19).

## Motif
Marginal rule stamps (R-XX in vermillion box), red marginalia line, punched paper edge, and ruler ticks. Repeated on every section.

## Principles
- Every visual decision has a written reason per R-31 (see this file).
- No blue-purple gradient (R-01), no glass everywhere (R-10), no glow spam (R-13), no Lucide default icon set (R-04), no pill-everything (R-11).

Dial: ENERGY 2 / RHYTHM 3 / MOTION 1
