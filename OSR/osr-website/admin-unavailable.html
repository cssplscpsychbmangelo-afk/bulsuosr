Run the CMS locally

  1. From the repository root, run cd OSR/server and npm ci.
  2. Copy .env.example to .env.
  3. Set a unique ADMIN_PASSWORD (12+ characters) and JWT_SECRET, then run npm start.

Then open http://localhost:4000/admin/login.html.

To use the CMS on the live domain, the Express server must be deployed to a Node host and Netlify must proxy the admin and API routes to it (set OSR_BACKEND_URL in Netlify → Site configuration → Environment variables, then redeploy).
