Admin CMS

The admin dashboard is not available on this host

This site is deployed as a static page. The admin CMS needs the OSR backend (Express + database), which does not run on static hosting.

To open the admin dashboard, run the full stack on a server:

  1. cd OSR/server && npm install
  2. Set JWT_SECRET in OSR/server/.env (see .env.example)
  3. node index.js then open /admin/login.html
