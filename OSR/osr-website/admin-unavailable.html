OSR Admin CMS

The CMS backend is not connected here

This public site is hosted as static files on Netlify. The admin dashboard requires the OSR Express server and database, so this host cannot sign you in.

Run the CMS locally

  1. From the repository root, run cd OSR/server and npm ci.
  2. Copy .env.example to .env.
  3. Set a unique ADMIN_PASSWORD (12+ characters) and JWT_SECRET, then run npm start.

Then open http://localhost:4000/admin/login.html.

To use the CMS on the live domain, the Express server must be deployed to a Node host and Netlify must proxy the admin and API routes to it.
